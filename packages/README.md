# packages

Shared TypeScript code and contracts, built with pnpm and Turborepo (05.01 §2.1).

| Folder | Content |
| --- | --- |
| `contracts/` | OpenAPI 3.1, `.proto`, event JSON Schema, role-operation matrix |
| `api-client/` | TypeScript client generated from the contracts |
| `ui/` | Shared React components, responsive (NFR-UX-03) |
| `config/` | ESLint, tsconfig and Prettier presets |
